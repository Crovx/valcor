# Valcor Studio | Sitio Web Oficial

Sitio web oficial de **Valcor Studio** — Estudio de diseño y desarrollo web de alto impacto enfocado en conversión y crecimiento digital.

## 🚀 Características
- **Diseño Ultra-Moderno:** Minimalismo de precisión (*Precision Minimalism*), tipografía Inter y paleta de marca corporativa.
- **Secciones Completas:** Hero de alto impacto, Servicios, Metodología de 4 pasos, Portafolio Seleccionado con modales, Planes & Precios transparentes (en MXN), FAQ y Cotizador interactivo con enlace directo a WhatsApp Business.
- **Rendimiento & SEO:** Diseñado para cumplir con los estándares de Google Core Web Vitals y diseño 100% responsivo.
- **Despliegue Inmediato:** Compatible con Vercel, Netlify o cualquier servidor estático.

## 🛠️ Tecnologías
- HTML5 Semántico
- Tailwind CSS
- Vanilla JavaScript
- Google Fonts (Inter) & Material Symbols
